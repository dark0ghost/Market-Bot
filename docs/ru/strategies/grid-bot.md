# Grid Bot - Сеточная торговля

Grid Bot автоматически размещает ордера на покупку и продажу по заранее определенной ценовой сетке. Стратегия эффективна на боковых трендах (флэте).

## Принцип работы

### Визуализация сетки

```
Цена (₽)
  300 ──────────────────────┐ Sell 5
  295 ───────────────────┐  │ Sell 4
  290 ─────────────────┐  │  │ Sell 3
  285 ───────────────┐  │  │  │ Sell 2
  280 ─────────────┐  │  │  │  │ Sell 1
  275 ─────────────┼──┼──┼──┼──┼── Текущая цена
  270 ─────────────┘  │  │  │  │ Buy 1
  265 ────────────────┘  │  │  │ Buy 2
  260 ───────────────────┘  │  │ Buy 3
  255 ──────────────────────┘  │ Buy 4
  250 ─────────────────────────┘ Buy 5
       │← шаг = 5₽ →│
```

### Алгоритм работы

1. **Инициализация**: Расчет уровней сетки
2. **Размещение**: Buy ордера ниже цены, Sell выше
3. **Исполнение**: При покупке размещается Sell с прибылью
4. **Перебалансировка**: Обновление при изменении цены на 2%+

## Конфигурация

### Базовая настройка

```json
{
  "accounts": [{
    "account_id": "grid_sber",
    "strategy": {
      "strategy": "grid",
      "parameters": {
        "grid_config": {
          "lower_price": 250.0,
          "upper_price": 300.0,
          "grid_levels": 11,
          "order_size": 10,
          "grid_ratio": 0.5
        }
      }
    },
    "instruments": [{
      "figi": "BBG004730N88",
      "ticker": "SBER",
      "enabled": true
    }]
  }]
}
```

### Параметры GridConfig

| Параметр | Тип | Описание | Пример |
|----------|-----|----------|--------|
| `lower_price` | f64 | Нижняя граница диапазона | 250.0 |
| `upper_price` | f64 | Верхняя граница диапазона | 300.0 |
| `grid_levels` | u32 | Количество уровней | 11 |
| `order_size` | u32 | Размер ордера в лотах | 10 |
| `grid_ratio` | f64 | Соотношение buy/sell | 0.5 |

### Расчет параметров

```python
# Шаг сетки
step = (upper_price - lower_price) / (grid_levels - 1)
# Для SBER: (300 - 250) / (11 - 1) = 5₽

# Количество Buy уровней
buy_levels = int(grid_levels * grid_ratio)
# Для grid_ratio=0.5: 11 * 0.5 = 5 уровней

# Количество Sell уровней
sell_levels = grid_levels - buy_levels
# 11 - 5 = 6 уровней
```

## Рекомендации по выбору диапазона

### Анализ истории

1. Откройте график за 1-3 месяца
2. Найдите минимум и максимум за период
3. Добавьте запас 10-15% с каждой стороны

### Пример для SBER

```
Исторический диапазон (3 месяца): 260-290₽
Рекомендуемый диапазон: 250-300₽
Запас: ~10%
```

### Волатильность

| Волатильность | Диапазон | Шаг | Уровней |
|---------------|----------|-----|---------|
| Низкая | Узкий (5-10%) | Малый | Много (20+) |
| Средняя | Средний (10-20%) | Средний | Средне (11-20) |
| Высокая | Широкий (20-30%) | Большой | Мало (<11) |

## Управление рисками

### Настройка Stop Loss

```json
{
  "risk_management": {
    "stop_loss_pct": 0.15,
    "max_loss_pct": 0.10,
    "min_balance_reserve": 50000.0
  }

```

### Расчет требуемого капитала

```python
# Для SBER 250-300₽, order_size=10, grid_levels=11
buy_levels = 5
avg_buy_price = 260  # Средняя цена покупки

# 5 * 10 * 260 = 13,000₽

# Рекомендуемый резерв

# 13,000 * 1.5 = 19,500₽
```

## Troubleshooting

### Цена вышла из диапазона

**Проблема:** Все ордера исполнены, цена ушла выше/ниже

**Решения:**
1. Расширьте диапазон
2. Увеличьте количество уровней
3. Временно остановите бота

### Недостаточно средств

**Проблема:** Ошибка при размещении ордеров

**Решения:**
1. Уменьшите `order_size`
2. Увеличьте `min_balance_reserve`
3. Уменьшите количество уровней

### Частая перебалансировка

**Проблема:** Ордера часто отменяются и размещаются

**Решения:**
1. Увеличьте порог перебалансировки (по умолчанию 2%)
2. Расширьте диапазон
3. Увеличьте `check_interval`
