# FAQ

## Tinkoff — "Token not found"
- Убедитесь, что токен начинается с `t.`
- Проверьте, что переменная `API_TOKEN` установлена, или токен указан в `account.json`
- Убедитесь, что у токена есть необходимые разрешения в режиме песочницы

## Tinkoff — Аккаунт песочницы не найден
- Включите `"open_account": true` в секции `sandbox` конфига для авто-создания при запуске
- Проверьте логи — бот пишет новый `account_id` после создания
- Sandbox-аккаунты удаляются после 3 месяцев неактивности; создайте новый если нужно
- Если вы указали `account_id`, который больше не существует, API вернёт ошибку — удалите его из конфига для авто-создания

## Finam — Ошибка аутентификации
- Проверьте корректность API секрета
- Обратитесь в поддержку Finam, чтобы убедиться, что доступ к API включён для вашего аккаунта

## Mock — Ордер не исполнился
- MockBroker исполняет ордера мгновенно. Проверьте что:
  - Цена инструмента установлена через `set_price()`
  - Достаточно средств на балансе
  - Не превышены лимиты позиций
