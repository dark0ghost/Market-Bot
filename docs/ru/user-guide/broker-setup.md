# Настройка брокеров

Проект поддерживает три брокерских бэкенда: Tinkoff, Finam и Mock (симулятор в памяти). Каждый предоставляет полный интерфейс трейта `Broker` для рыночных данных, управления ордерами и запросов портфеля.

## Обзор поддерживаемых брокеров

| Возможность | Tinkoff | Finam | Mock |
|-------------|---------|-------|------|
| Рыночные данные (свечи) | ✅ gRPC | ✅ REST | ✅ синтетические |
| Последняя цена | ✅ | ✅ | ✅ настраиваемая |
| Стакан | ✅ | ✅ | ✅ синтетический |
| Размещение/отмена ордеров | ✅ | ✅ | ✅ симуляция |
| Портфель и баланс | ✅ | ✅ | ✅ симуляция |
| Песочница/бумажная торговля | ✅ `Environment::Sandbox` | ❌ только продакшн | ✅ встроенная |
| Режим продакшн | ✅ | ✅ | - |
| Требуется API токен | ✅ | ✅ | ❌ |
| SDK | `t-invest-sdk 0.17` | raw `reqwest` | none |

## Tinkoff Invest

[Tinkoff Invest](https://www.tinkoff.ru/invest/) предоставляет среду **песочницы** (бумажная торговля виртуальными деньгами) и **продакшн** (реальные деньги).

### 1. Получить API токен

1. Перейдите в [Tinkoff Invest API](https://www.tinkoff.ru/invest/settings/api/)
2. Нажмите **"Создать токен"**
3. Выберите необходимые разрешения:
   - Для песочницы: любые разрешения (виртуальные деньги)
   - Для продакшна: чтение + торговля
4. Скопируйте токен (начинается с `t.`)

### 2. Настройка песочницы (бумажная торговля)

Установите режим `sandbox` в `trader-bot/config/account.json`:

```json
{
  "creditional": {
    "token": "t.YOUR_TINKOFF_TOKEN"
  },
  "mode": "sandbox",
  "accounts": [
    {
      "account_id": "main",
      "broker": "tinkoff",
      "instruments": [
        {
          "figi": "BBG004730N88",
          "ticker": "SBER",
          "name": "Сбербанк",
          "enabled": true,
          "max_position_pct": 0.2
        }
      ],
      "strategy": {
        "strategy": "interval",
        "parameters": {
          "interval_size": "1h",
          "days_back_to_consider": 30,
          "quantity_limit": 1000,
          "check_interval": 60
        }
      },
      "risk_management": {
        "max_loss_pct": 0.05,
        "take_profit_pct": 0.10,
        "stop_loss_pct": 0.03,
        "max_open_positions": 5,
        "min_balance_reserve": 100000.0
      }
    }
  ]
}
```

Поле `mode: "sandbox"` заставляет SDK подключаться к `Environment::Sandbox` - все ордера исполняются виртуальными деньгами. Реальные средства не используются.

Токен также можно передать через переменную окружения (удобно для CI/CD или хранения секретов вне VCS):

```bash
export API_TOKEN="t.YOUR_TINKOFF_TOKEN"
```

Оставьте токен пустым в конфиге:

```json
{
  "creditional": { "token": "" },
  "mode": "sandbox"
}
```

### 3. Настройка продакшна (реальные деньги)

Измените режим на `prod`:

```json
{
  "mode": "prod"
}
```

**⚠️ ВНИМАНИЕ:** В режиме продакшн бот будет использовать **реальные деньги**. Убедитесь, что ваша стратегия тщательно протестирована в песочнице.

### 4. Авто-создание аккаунта песочницы

Когда `mode: "sandbox"`, можно настроить автоматическое создание и пополнение счёта:

```json
{
  "mode": "sandbox",
  "sandbox": {
    "open_account": true,
    "pay_in_amount": 30000000
  }
}
```

| Поле | По умолчанию | Описание |
|------|-------------|----------|
| `open_account` | `true` | Авто-создание счёта через `OpenSandboxAccount`, если `account_id` не указан или пуст |
| `pay_in_amount` | `30000000` | Сумма в RUB для зачисления через `SandboxPayIn` (макс. 30M) |

Если `account_id` указан в конфиге - используется как есть (создание не происходит). Если пустой или отсутствует - бот вызывает `OpenSandboxAccount`, логирует новый ID счёта и зачисляет тестовую сумму.

**Важно:** Sandbox-аккаунты удаляются после 3 месяцев неактивности. Запишите `account_id` из логов - его можно указать в конфиге, чтобы переиспользовать тот же счёт между перезапусками.

## Finam Trade API

[Finam Trade API](https://www.finam.ru/) предоставляет REST API доступ к реальной торговле (песочница/бумажная торговля недоступна - только продакшн).

### 1. Получить учётные данные

1. Обратитесь в поддержку Finam или к вашему брокеру для получения доступа к API
2. Вы получите API секрет/токен

### 2. Настройка

Учётные данные Finam указываются в `additional_keys`:

```json
{
  "creditional": {
    "token": "",
    "additional_keys": [
      {
        "broker": "finam",
        "api_key": "YOUR_FINAM_API_SECRET",
        "secret_key": null,
        "extra": null
      }
    ]
  },
  "mode": "sandbox",
  "accounts": [
    {
      "account_id": "finam_main",
      "broker": "finam",
      "instruments": [...]
    }
  ]
}
```

### 3. Формат символов

Finam использует `@` как разделитель в идентификаторах инструментов (например, `SBER@TQBR`). Внутри код конвертирует между `_` и `@`:

| Внутренний | Finam API |
|------------|-----------|
| `SBER_TQBR` | `SBER@TQBR` |

## Mock Broker (встроенный симулятор)

`MockBroker` - это реализация брокера в памяти для тестирования и бэктестинга. Не требует **ни API токенов, ни сети, ни внешних сервисов**.

### Использование

```rust
use trader_bot::broker::MockBroker;

let broker = MockBroker::new("test".to_string(), 1_000_000.0);
broker.set_price("SBER", 250.0);
broker.set_candles("SBER", candles); // загрузить исторические данные
```

Возможности MockBroker:
- **Мгновенное исполнение ордеров** - все лимитные/рыночные ордера исполняются сразу
- **Отслеживание баланса** - операции покупки/продажи обновляют баланс
- **Отслеживание позиций** - средневзвешенная стоимость для накопленных позиций
- **Расчёт PnL** - реализованная прибыль/убыток вычисляется при продаже
- **Синтетический стакан** - bid = цена × 0.999, ask = цена × 1.001
- **Синтетическая ликвидность** - константные значения

### Тестирование с MockBroker

```rust
#[tokio::test]
async fn test_strategy_with_mock() {
    let broker = MockBroker::new("test".to_string(), 100_000.0);
    broker.set_price("SBER", 250.0);

    let price = broker.last_price("SBER").await.unwrap();
    assert_eq!(price, 250.0);

    let balance = broker.balance().await.unwrap();
    assert_eq!(balance, 100_000.0);
}
```

## Матрица поддержки по типу брокера

| `BrokerKind` | Реализован | Песочница | Продакшн | Примечания |
|-------------|------------|-----------|-----------|------------|
| `Tinkoff` | ✅ | ✅ `Environment::Sandbox` | ✅ | Основной брокер |
| `Mock` | ✅ | Н/Д (всегда симуляция) | Н/Д | Только тестирование |
| `Other("finam")` | ✅ | ❌ | ✅ | REST API |
| `Alor` | ❌ только в enum | - | - | Не реализован |
| `Binance` | ❌ только в enum | - | - | Не реализован |
| `ByBit` | ❌ только в enum | - | - | Не реализован |
| `InteractiveBrokers` | ❌ только в enum | - | - | Не реализован |

## Переменные окружения

| Переменная | Назначение | Пример |
|------------|------------|--------|
| `API_TOKEN` | Токен Tinkoff Invest API | `t.YOUR_TOKEN` |
| `RUST_LOG` | Уровень логирования | `info`, `debug`, `warn` |
| `LOG_FILE` | Путь к файлу лога | `/var/log/trader-bot.log` |
| `LOG_WEBHOOK` | URL вебхука для логов | `https://logs.example.com/ingest` |
| `LOG_LEVEL` | Переопределение уровня лога | `debug` |
