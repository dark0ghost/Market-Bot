# Поддерживаемые брокеры

## MockBroker

Брокер в памяти для бэктестинга и интеграционных тестов. Всё состояние хранится в `Arc<Mutex<MockState>>` - без сетевых запросов.

**Для чего нужен:** тестировать стратегии без реальных денег и API-ключей. Вы наполняете его свечами и ценами, затем прогоняете решения. Любой ордер исполняется мгновенно по текущей цене. Используется в unit-тестах и CI.

```rust
let broker = MockBroker::new("test".into(), 100_000.0);
broker.set_candles("SBER", candles);
broker.set_price("SBER", 285.0);
broker.set_position("SBER", 100, 280.0);
```

Ограничения: нет частичного исполнения, нет задержек, нет внешнего состояния.

## TinkoffBroker

Полнофункциональный брокер через `t-invest-sdk` (gRPC). Использует Tinkoff Invest API.

| Возможность | Статус |
|-------------|--------|
| Свечи (M1, M5, M15, H1, H4, D) | ✅ |
| Стакан | ✅ |
| Размещение/отмена ордеров (Limit, Market) | ✅ |
| Стоп-лосс / Тейк-профит | ✅ (SDK) |
| Портфель и позиции | ✅ |
| Sandbox-режим | ✅ |
| Стриминг (стакан, сделки) | ✅ (gRPC потоки) |
| Поиск инструментов | ✅ |
| GridBot | ✅ (требует стриминг) |

Конфигурация: `api_key` и опционально `secret_key`. Тип аккаунта `"tinkoff"` в конфиге.

## FinamBroker

REST/JSON брокер через `https://api.finam.ru`. Без SDK - прямые `reqwest` вызовы.

| Возможность | Статус |
|-------------|--------|
| Свечи (M1, M5, M15, H1, H4, D) | ✅ |
| Стакан | ✅ |
| Размещение/отмена ордеров (Limit, Market) | ✅ |
| Стоп-лосс / Тейк-профит | ❌ |
| Портфель и позиции | ✅ |
| Sandbox-режим | ❌ |
| Стриминг | ❌ |
| Поиск инструментов | ✅ |
| GridBot | ❌ (нет Tinkoff SDK) |

Аутентификация: `POST /v1/sessions` с API-секретом → bearer token. Формат символов: `TICKER@MIC` (например `SBER@MISX`).

Конфигурация через `additional_keys` с `broker: "finam"`.

## Сравнение

| | Mock | Tinkoff | Finam |
|--|------|---------|-------|
| Транспорт | В памяти | gRPC | REST |
| Реальные деньги | Нет | Да (или sandbox) | Да |
| Скорость | Мгновенно | Сеть | Сеть |
| Назначение | Тесты, CI | Живая торговля | Живая торговля (альт.) |
| BrokerKind | `Mock` | `Tinkoff` | `Other("finam")` |
