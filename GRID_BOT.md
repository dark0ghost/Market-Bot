# Grid Trading Bot — Документация

## Обзор

Grid Trading Bot — это стратегия автоматической торговли, которая размещает ордера на покупку и продажу по заранее определенной ценовой сетке. Стратегия эффективна на боковых трендах (флэте), когда цена колеблется в определенном диапазоне.

## Принцип работы

```
Цена:  300 ──────────────────────┐ Sell 5
       295 ───────────────────┐  │ Sell 4
       290 ─────────────────┐  │  │ Sell 3
       285 ───────────────┐  │  │  │ Sell 2
       280 ─────────────┐  │  │  │  │ Sell 1
       275 ─────────────┼──┼──┼──┼──┼── Текущая цена
       270 ─────────────┘  │  │  │  │ Buy 1
       265 ────────────────┘  │  │  │ Buy 2
       260 ───────────────────┘  │  │ Buy 3
       255 ──────────────────────┘  │ Buy 4
       250 ─────────────────────────┘ Buy 5
```

1. **Инициализация**: Бот рассчитывает уровни сетки на основе диапазона цен
2. **Размещение ордеров**: 
   - Buy ордера размещаются ниже текущей цены
   - Sell ордера размещаются выше текущей цены
3. **Исполнение**: При срабатывании ордера размещается противоположный ордер с прибылью
4. **Перебалансировка**: При изменении цены на 2%+ сетка обновляется

## Конфигурация

### Пример конфигурации account.json

```json
{
  "type": "trading",
  "creditional": {
    "token": "YOUR_API_TOKEN"
  },
  "accounts": [
    {
      "account_id": "grid_sber",
      "instruments": [
        {
          "figi": "BBG004730N88",
          "ticker": "SBER",
          "name": "Сбербанк",
          "enabled": true,
          "max_position_pct": 0.30,
          "analysis_config": {
            "check_news": false,
            "technical_analysis": false,
            "fundamental_analysis": false,
            "news_sources": [],
            "technical_indicators": [],
            "fundamental_metrics": []
          }
        }
      ],
      "strategy": {
        "strategy": "grid",
        "parameters": {
          "interval_size": "1h",
          "days_back_to_consider": 1,
          "quantity_limit": 1000,
          "check_interval": 30,
          "grid_config": {
            "lower_price": 250.0,
            "upper_price": 300.0,
            "grid_levels": 11,
            "order_size": 10,
            "grid_ratio": 0.5
          }
        }
      },
      "risk_management": {
        "max_loss_pct": 0.10,
        "take_profit_pct": 0.05,
        "stop_loss_pct": 0.15,
        "max_open_positions": 10,
        "min_balance_reserve": 50000.0
      }
    }
  ],
  "mode": "sandbox",
  "llm_config": {
    "model": "fin-expert",
    "host": "http://localhost",
    "port": 11435,
    "temperature": 0.3,
    "context_window": 4096
  }
}
```

### Параметры GridConfig

| Параметр | Тип | Описание | Пример |
|----------|-----|----------|--------|
| `lower_price` | f64 | Нижняя граница диапазона (цена) | 250.0 |
| `upper_price` | f64 | Верхняя граница диапазона (цена) | 300.0 |
| `grid_levels` | u32 | Количество уровней сетки | 11 |
| `order_size` | u32 | Размер ордера в лотах | 10 |
| `grid_ratio` | f64 | Соотношение buy/sell (0.5 = 50/50) | 0.5 |

### Расчет шага сетки

```
Шаг = (upper_price - lower_price) / (grid_levels - 1)

Пример для SBER:
Шаг = (300 - 250) / (11 - 1) = 50 / 10 = 5₽
```

### Расчет количества ордеров

```
Buy уровни = grid_levels * grid_ratio
Sell уровни = grid_levels - Buy уровни

Пример:
Buy = 11 * 0.5 = 5 уровней
Sell = 11 - 5 = 6 уровней
```

## Запуск

### 1. Установка токена

Получите токен в личном кабинете Tinkoff Invest:
https://www.tbank.ru/invest/settings/

Добавьте токен в `trader-bot/config/account.json`:
```json
{
  "creditional": {
    "token": "YOUR_TOKEN_HERE"
  }
}
```

Или через переменную окружения:
```bash
export API_TOKEN="YOUR_TOKEN_HERE"
```

### 2. Запуск бота

```bash
# Сборка проекта
cargo build -p trader-bot

# Запуск в режиме sandbox (тестовый режим)
cargo run -p trader-bot

# Запуск в боевом режиме (измените mode на "prod" в конфиге)
cargo run -p trader-bot --release
```

### 3. Логирование

Установите уровень логирования:
```bash
RUST_LOG=info cargo run -p trader-bot
RUST_LOG=debug cargo run -p trader-bot  # Подробные логи
```

### Рекомендации по выбору диапазона

1. **Анализ истории**: Изучите диапазон цен за последние 1-3 месяца
2. **Волатильность**: Для волатильных бумаг выбирайте широкий диапазон
3. **Ликвидность**: Убедитесь в достаточной ликвидности инструмента

## Риски и управление

### Основные риски

1. **Выход из диапазона**: Цена может выйти за пределы диапазона
   - Решение: Установите stop_loss_pct в конфиге

2. **Недостаточный баланс**: Для работы нужен резерв
   - Решение: Установите min_balance_reserve

3. **Падение ликвидности**: Ордера могут не исполняться
   - Решение: Используйте ликвидные инструменты

### Параметры риск-менеджмента

```json
"risk_management": {
  "max_loss_pct": 0.10,      // Макс. потеря от баланса (10%)
  "take_profit_pct": 0.05,   // Фиксация прибыли (5%)
  "stop_loss_pct": 0.15,     // Стоп-лосс (15%)
  "max_open_positions": 10,  // Макс. открытых позиций
  "min_balance_reserve": 50000.0  // Мин. резерв (₽)
}
```

## Troubleshooting

### Ошибка: "Инструмент не найден"
- Проверьте FIGI в конфигурации
- Убедитесь, что инструмент доступен для торговли

### Ошибка: "Недостаточно средств"
- Увеличьте min_balance_reserve
- Уменьшите order_size
- Проверьте доступный баланс

### Ошибка: "Grid состояние не инициализировано"
- Проверьте подключение к API
- Убедитесь, что цена получена корректно
